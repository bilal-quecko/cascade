# Cascade

Cascade is a Unity mobile physics-puzzle project built around readable chain reactions, reusable level architecture, and event-based Cascade scoring.

## Unity version

Unity 2022.3.61f1 (LTS)

## Project layout

All game-specific content lives under `Assets/_Cascade/`. Shared gameplay scenes are in `Assets/_Cascade/Scenes/`, while data, prefabs, systems, art, audio, UI and settings are separated by responsibility.

The repository includes the minimum Unity project metadata required for Unity Hub to recognize and open the project. Empty content folders contain temporary `.gitkeep` files because Git cannot track empty directories; remove a `.gitkeep` once a real asset is added to that folder.
